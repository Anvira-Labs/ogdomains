# How a portfolio should look

The blank template (every "Personal Names" door in the mall) follows these rules. The page itself carries a
short hint under each heading; this is the longer version.

**Goal.** In ten seconds a stranger knows who you are, what you are good at, that you can prove it, and how to reach you.

| Section | What goes in it | Rule of thumb |
|---|---|---|
| Identity (left rail) | Photo, name, role, contact links | Stays in view while scrolling. One role, not five. |
| Headline | "I help *who* do *what* so that *result*." | One sentence. No buzzwords. |
| About | Who you are, what you are good at, what you want next | 2 to 3 short paragraphs, under 120 words. |
| Selected work | Three case studies | Each is *problem → what I did → result*. Use a real number where you have one. Three, not thirty. |
| Skills | Grouped by kind | Only what you would happily be asked about. No percentage bars. |
| Experience | Newest first | One line of impact per role. Link the full CV. |
| Writing & talks | Optional | Only if it adds proof. |
| Contact | One clear next step | Say what to write about and how fast you reply. |

**Look.** Light background, one accent colour, one typeface family, generous whitespace, single column on a phone.
Real photo, clear face. Placeholders are drawn as dashed grey boxes so nothing half-finished looks finished.

**Quality bar.** Readable contrast, keyboard reachable, loads fast, no autoplay, every link works, nothing claimed that
you cannot show. Only publish facts about a real person with that person's consent.

**To fill one in**, add an entry to `js/profiles.js` keyed by the domain's id (for example `raghu-si`); the format is
documented at the top of that file. With no entry the page stays the blank template.
